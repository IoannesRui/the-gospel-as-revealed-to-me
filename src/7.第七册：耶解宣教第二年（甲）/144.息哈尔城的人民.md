# 第七册 | 144.息哈尔城的人民

1945年4月23日

144.1傅提乃带者一群显要的人，走向耶稣。

「天主与你相偕，辣彼。这位妇女说你是一位先知，不嫌弃和我们说话。所以，我们恳求你留下，跟我们宣讲。我们被隔绝，并不代表只有犹大很圣洁；也不意谓着一切的罪都归于撒玛黎雅人，我们中间也有义人 。」

「我的确也跟她这样说了。我不勉强人接受我的看法，也不拒绝那些寻求我的人。」

144.2

「你很中肯。这妇女还说你是基督，是真的吗？奉天主之名，请答复我们。」

「是的，我是。默西亚的时代已经来临了！以色列将由他的君王重新团结起来，但并不只是以色列。」

「但你只是他们的默西亚……而不是我们这些背负恶名者的默西亚。」一位令人肃然起敬的老人指出。

「人哪，我看你是他们的首领，也看出你是真心诚意寻求真理。因为你熟悉圣经，现在，请听厄则克耳先知充满圣神后，论及有关我的预言：『人子（厄则克耳先知），我派遣你到以色列人当中，这悖逆的民族，他们背叛了我……是一群无耻与执拗的儿女……他们可能会听，然而却不遵守你的话；其实那是我的话，只因为他们生来就是悖逆，但至少他们会知道，在他们当中有一位先知！

为此，不必害怕，也不要畏惧他们的言语，因为他们不信和悖逆……你只要把我的话转述给他们，不管他们听或是拒绝，尽管照我所说的去做。听我说不要像他们那样叛逆！所以，无论我给你任何食物，吃吧！』（参厄二:1～8）我来了，并没有吹捧自已，也没有期望像胜利者般的被接待。因为天主的旨意是我的蜜汁，我来是承行祂的旨意！如果你们愿意，我将告诉你们圣神对我说的话 。」

「永恒之父怎么可能想到我们？」

「我的孩子们，因为祂是爱！」

「犹大的辣彼，不这么说。」

「这话是上主的默西亚，对你们说的！」

144.3

「经上记载默西亚生于犹大的一位童贞女。祢母亲是谁，祢在哪里出生？」（参米五：1）

「在厄弗辣大白冷，生于达味家族的玛利亚。她以神性的方式受孕！你们要相信我。」耶稣以优美的声调，充满着喜悦，胜利地宣告了祂母亲的童贞。

「祢的脸闪耀着光芒。不，祢不可能撒谎！黑暗之子的脸是阴沉的，眼神不安；而祢却充满了光明，祢的眼睛明亮有如晨星，祢的话很真实！请来息哈尔教导我们的子孙。当祢离去后，我们会记得撒玛黎雅的天空，曾经出现过那颗明亮的晨星……」（参默廿二：6）

「你们为什么不追随那晨星？」

「我们怎么可能？」他们一边谈论，一边走向城镇 。

「我们被隔绝了！至少他们是这样说的。可是，我们生于这个信仰，但现在到底是应该坚持，还是要放弃！至于……我觉得可以告诉你，毕竟，我们有眼睛在看，头脑在思考……当我们旅行或作买卖时，经过你们的地区，所看到的一切，不是那么神圣；所以根本无法说服我们，天主是和你们犹太人或加里肋亚人同在 。」

「我实实在在告诉你们，有些以色列人，因为没有藉由善表和爱德，去吸引你们归向天主，反而触怒和诅咒你们，那些人将受谴责！」

「在你内充满了智慧！你们都听到了吗？」

他们都点头同意，窃窃私语钦佩耶稣的智慧！

144.4

此时已经抵达了镇上，当他们走向一所住宅，更多的人尾随着。

「辣彼，请听。由于祢充满了智慧和良善，请解开我们的疑惑；祢的答复将深深影响我们的未来……因为祢是默西亚以及达味王国的重建者，祢是否乐意将这分离的断肢，重新接回以色列国？」

「我并不那么看重这些易于腐朽和短暂的断肢，是否重新接回以色列国；我更在乎众人的灵魂归向天主。当我在人心重建真理时，就是我的喜乐！但你可以表达自己的疑惑 。」

「我们的祖先犯了罪。自那时起，天主便不喜欢撒玛黎雅人的灵魂 。在天主眼中，我们就像个癞病人，那么，行善对我们有什么益处呢？」

「你们的悲叹，也就是分裂的教徒长期以来的不快！我再次引用厄则克耳先知的话（参则十八：4～29） ，来回答你们：『所有的灵魂都属于我。上主说：无论父亲或儿子的灵魂都归我所有！只有犯罪的灵魂该死（参罗六：23） 。

如果一个人正直，他不崇拜偶像，不犯奸淫，不偷窃，不放贷；他怜悯对待邻人的身体和灵魂，在我眼里，他是正义的，将享有真生命 。』又说：『如果一个正义的父亲，有个叛逆的儿子，儿子是否会因为父亲是义人，而得以生存？不！』同样：『如果父亲是个罪人，儿子却是个义人，儿子是否会像父亲一样地丧亡？只因为他们是父子关系？不，儿子将享有永生，因为他正直！』

一个人为了别人的不法行为而受苦，是不公平的。犯罪的那个灵魂该死；没有犯罪的灵魂不必死。但若罪人悔改，归向“公义”，他也将享有真生命！上主天主，独一而且唯一的上主，说：『我不乐见罪人丧亡，但我希望他们改过迁善而生存（参则十八：23） 。』

这是祂派遣我来的原因。啊！漂泊的孩子们：为了使你们得到真正的生命，我就是那“生命” 。谁若相信我和相信派遣我来者，将有永生，即使他曾经在罪恶中生活过（参若十七：3） 。」

「师傅，这是我家，如果祢不嫌弃的话，请进 。」

「我讨厌的只是罪 。」

「那么，请进并留下。我们一起擘饼用餐，然后，如果不成为祢的负担，请为我们解说天主的话语。这些话从祢的口中说出，味道就不一样……我们长期被一个疑惑所困扰，就是无法肯定我们的立场是否正确……」

「如果你们敞开胸怀投奔“真理” ，一切都会得到解答。愿天主向你们说话！现在天色已晩，明日早上，第三个时辰（九点），如果你们愿意，我会向你们详细说明。去吧，天主的“仁慈”已离你们很近。」
