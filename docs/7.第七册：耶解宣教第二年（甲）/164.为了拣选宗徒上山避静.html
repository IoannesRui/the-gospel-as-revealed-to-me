我见我闻的福音

第七册 | 164.为了拣选宗徒上山避静

1945年5月15日

164.1

伯铎和若望的渔船在平静的湖面行驶，尾随在后的，我（华多达）认为是提

庇黎雅所有的船只，大大小小，为数众多的在水上来来往往……有些想接近或超越耶稣的船，有的跟在耶稣后面，形成了一列长长的队伍。在碧波荡漾的湖上，传来不绝于耳的祈祷声、各种恳求、哀告、以及吶喊！

耶稣应允和回答及降福群众。与祂同船的，有圣母玛利亚，和雅格及犹大的母亲。在另一艘船上，是玛利亚撒罗默和她的儿子若望以及苏撒纳。

「是的，我会回来。我答应你们！要善良喔。记住我的话，以便日后我再告诉你们其它的话时，能串连起来……我不会去太久。不要自私。我也为其他的人而来。要成为好人！你们会伤害自己。是的，我会为你们祈祷。我经常和你们一起 。愿上主与你们同在！当然，我会记得你的眼泪，你将得到安慰……你一定要保持希望和信德。」

就这样， 一面降福一面承诺……船不断前进抵达了岸边。这地方不是提庇黎雅镇，而是个荒凉的小村落，只有几间破旧的房屋。

耶稣和门徒们下了船，把渔船交给仆人和载伯德，便让他们回去了。也有些船只跟着离开；但仍有很多人，不惜任何代价跟随耶稣一起上岸。其中我看见依撒格和他的两个助手：若瑟和弟茂内奥，及各种年龄层，老老少少一大群人，但我并不认识他们 。

164.2

耶稣离开了村庄，有几个衣衫褴褛的居民，一副漠不关心的样子，耶稣还是给了他们救济金后，便走向大路。

祂停下脚步说：「妈妈，妳和（伯母）玛利亚及撒罗默回去纳匝肋，苏撒纳可以回去加纳。我很快就回来！妳们都了解该怎么做。愿天主与妳们同在！」

面对自已的母亲，耶稣有一种特殊的致意！祂笑容可掬；而为了树立典范和得到耶稣的降福，玛利亚率先跪了下来……耶稣充满了仁慈的微笑。于是妇女们和撒辣的阿尔斐以及西满，便走向了他们的城镇。

耶稣向那些留下来的人，说：「我离开你们，并不是要遣散你们，只是暂时离去，因为我与门徒要到山上的峡谷避静，你们可以看见就在那山头。谁若愿意等我回来，可以留在平原；不希望等待的人，可以回去。为了重要的事情即将来临，我要闭关祈祷 ！

而谁若为了爱天父的缘故，可以在灵里与我一同祈祷。平安与你们相偕，我的孩子们。依撒格，你知道该怎么做，我降福你，我的小牧者！」耶稣向消瘦的依撒格微笑，他现在成了一些与他聚集的人的牧者。

164.3

耶稣坚定地走向山中的峡谷，距离湖岸渐行渐远。峡谷位于湖的西边，山上有一条细长的瀑布，溅起了无数的水花，在崎岖的山峰间倾泻直下，奔腾的水声嘎嘎作响……在山涧的顶端是个原始的山脉，植物由四面八方奇形怪状的生长，也有些从缝隙中探出头来…… 耶稣选择了一条非常狭窄陡峭、崎岖多石的小径，往上攀爬！

门徒们困难地跟随耶稣，他们默不作声，一个跟着一个，在祂后面行走。直到抵达略微开阔的地方，耶稣才停下脚步，让他们喘口气。门徒们一言不发，彼此互相观望，眼神却透露着：「祂到底要带我们去哪里？」但是没有人发言。

当耶稣继续朝着荒山野岭往上爬，他们的眼神更是无助地互相对望；沿途上，有许多洞穴和裂缝以及岩石，令人寸步难行，还有些荆棘丛和有刺的灌木，经常勾破衣服，划伤了他们，以至于跌跌撞撞，刮花了脸部！又因为较年轻的几个，背负着沉重的袋子前进，已失去了他们往日的幽默感…… 。

164.4耶稣终于停下了脚步，开口说：「为一件重要的事情装备你们，我们会留在

这里祈祷一个星期。这也是为什么我要把你们隔绝于荒山野外，远离尘嚣。而此

处的山洞曾经有人使用过，现在你们正好可以利用。这里的水源清凉丰沛，地面也很干燥；在逗留的期间，我们有足够的面包和食物。

去年和我一起去过严斋山的几位，知道我是如何在那里生活…… 相较之下，此处算是皇宫！现在的季节气候温和，没有风霜雪雨或酷热的太阳。所以，你们可以快快乐乐地留在这里！也许我们不再有机会，像现在这样不受干扰的独处了。这次的避静必须把你们结合在一起，不再是十二个人，而是合一的体制！

你们不讲话，没有问题要问吗？将你们背负的重担放在岩石上；把你们心中的另一种负荷丢进山谷里——那就是你们的人性。

我带你们来这里，是要与你们的心灵说话，滋养你们的灵魂，好成为属灵人。我将不再多说，因为过去和你们共处的一年里，我已经讲了许多，已足够了。如果我只靠言语改变你们，也许还要守着你们十年……甚至一百年，你们仍然不完美 。

现在时候到了，我要使用你们，而若要用你们，就必须塑造你们。所以，我不得不求助于那伟大的良药和神兵利器：祈祷！我一直为你们祈祷，但现在我要你们自己祈祷。我还不曾教过你们，我的祷文；可是我会告诉你们如何祈祷，什么是祈祷 。

那是儿女与天父的对话，人灵与神灵的沟通，一种开放、温暖、信赖、宁静和坦诚的交谈。祈祷是一切：它是告白、认识自己、忏悔、对自己及对天主的承诺，向天主的一个恳求，都是在天父脚前作的。

祈祷不能在喧哗中完成，也不该分心走意，除非自己是个祈祷的巨人。即使巨人在他们祈祷的时候，也会受到世界杂音的干扰；何况你们不是巨人，是侏儒。你们的灵只算初生的要儿，有所不足。但你们在这里将达到灵命的成熟期！其余的会随之而来 。

在早晨、中午和傍晩，我们聚集在一起，用以色列传统的祷词祈祷和擘饼 。然后，你们每个人回到自己的山洞，在天主及你们的灵魂面前，去面对我告诉你们有关的使命和你们的能力；衡量自己，倾听自己的心声，做个抉择。我现在是最后一次跟你们说，日后你们必须迈向成全，尽自已最大的能耐，努力不懈，摆脱你们人性的枷锁！

这样你们将不再是约纳之子西满、西满之子犹达斯、也不再是安德或若望、玛窦或多默；你们将成为我的执行者（ministers）！

去吧，你们各自回去。我就在那个山洞，会一直待在那里。若没有充分的理由，不要来找我。你们必须学习独立自主！我郑重地告诉你们，一年以前，我们刚互相认识，而再过两年，我们将分手。如果你们没有学会独立，为你为我都是有祸的！愿天主与你们同在。

犹达斯、若望，把食物搬进我那边的山洞。这些食物必须维持到我们结束，我会分给你们。」

「食物不够！ ……」有人提出异议。

「足够了，不至于饿死。肚腹太满，灵魂就会迟钝！我希望提升你们，而不使你们下沉。」
